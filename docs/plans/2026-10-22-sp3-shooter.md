# Sub-project 3: shooter suite, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turret that aims at the right target all the time, hood and flywheel set from distance,
a feed that runs only when the shot is ready; all in sim.

**Architecture:** Pure math (`ShotTable`, `TurretMath`, `ShotCalculator`) with JUnit tests;
subsystems `Turret`, `Hood`, `Flywheel`, `Feeder` (indexer + Scotty + vertical roller) with real
Talons; `Superstructure` builds the commands; a shared `RollerSim`.

**Spec:** `docs/specs/2026-10-22-nick-test-rewrite-design.md`, section "Sub-project 3".

## Global Constraints

- Global constraints of the sub-project 1 plan apply.
- Turret angle 0 = jig = robot-relative +90 degrees. Soft limits +-250 degrees.
- Alerts via `AlertPublisher.create("Health", "shooter/...")`.

## Review Focus

1. **Target straight behind the turret's cable limit:** the chosen angle must stay inside the
   limits (go the long way round). Test in Task 1.
2. **No alliance (no DS):** blue hub. Test in Task 2.
3. **Turret Talon reboot:** aiming stops, feed never starts (not ready). Covered by the
   `isZeroed()` gate in Task 4.
4. **Trigger released mid-feed:** feed stops at once; flywheel coasts; hood stows.
5. **Robot on the alliance line:** target switches hub/pass without a crash (hysteresis not
   needed: the zone rule is a single comparison).

### Task 1: ShotTable and TurretMath (pure)
- `ShotTable(double[][] points)`, `double get(double distance)` (clamped at the ends).
- `TurretMath.chooseAngle(double wantedRot, double currentRot, double minRot, double maxRot)`.
- Tests: interpolation and clamping; nearest equivalent angle; long way round at a limit;
  target unreachable (outside +-limits with the 360 gap) returns the nearest limit.

### Task 2: ShotCalculator (pure)
- `record Shot(Translation2d target, boolean scoring, double distance, double turretRot,
  double flywheelRps, double hoodDeg)`; `Shot calculate(Pose2d robot, ChassisVelocities fieldVel,
  double robotOmega, boolean red, double currentTurretRot)`.
- Tests: robot facing +x at a known point: hub straight left gives turret 0 (jig); hub straight
  ahead gives -0.25 rot; pass target outside our zone; no alliance = blue; lead points against
  the field velocity when time of flight > 0.
